# Ridwan Farah - Portfolio Website

Professional portfolio website for Ridwan Abdillahi Farah, Electrical & Electronics Engineer.

## Features
- Responsive design for all devices
- Multi-language support (English/Somali)
- Interactive profile picture with update functionality
- Project gallery and video showcase
- Contact form with validation
- Downloadable resume
- SEO optimized

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons
- GitHub Pages for hosting

## How to Update Profile Picture
1. Save your photo as `profile.jpg`
2. Place it in the `img` folder
3. Refresh the website
