Projects

Vehicle ECU Diagnostic App

Built a diagnostic tool for vehicle ECUs using Arduino and Bluetooth to read and clear fault codes. The system interfaces with OBD-II ports and provides real-time data visualization on a mobile app.

Technologies: Arduino, Bluetooth LE, Android, OBD-II

Smart Home IoT System

Designed a smart home prototype using NodeMCU and sensors for automation. Features energy monitoring, security, and remote control via a web dashboard.

Technologies: ESP8266, MQTT, Firebase, JavaScript

EV Battery Management System (BMS)

Prototype BMS for EV applications with STM32. Monitors cell voltages & temperatures and implements balancing algorithms to extend battery life.

Technologies: STM32, CAN Bus, Li-ion, Embedded C

Solar-Powered Water Pumping System

Off-grid solar water pumping solution for a rural community, reducing diesel generator usage by ~90%.

Technologies: Solar PV, Pump Controllers, Energy Storage
